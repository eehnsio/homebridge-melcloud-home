MELCloud Home - Authentication Setup

Enter your MELCloud credentials to get your authentication token. Settings are saved automatically.

Step 1: Get Your Token
MELCloud revokes the login every few weeks, at no fixed interval. This saves your password here, encrypted, so the plugin can sign back in by itself instead of your ACs going "Not Responding" until you return and press Login.
Encryption keeps the password out of screenshots, shared config files and backups. It is not protection against someone who already has access to this server — the plugin must be able to decrypt it unattended.
Your saved password can no longer be decrypted, so automatic sign-in is off. Log in below with "Stay signed in" ticked to restore it.
Your credentials are sent directly to MELCloud's servers. They are only stored if you tick "Stay signed in" above.
